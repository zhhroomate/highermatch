## 演示注意事项

### 可能遇到的问题及应对

| 问题 | 原因 | 应对措施 |
|------|------|----------|
| 语音输入无响应 | 浏览器权限 | 提前在浏览器设置中允许麦克风权限 |
| 匹配耗时过长 | Kafka 延迟 | 预先生成匹配结果，跳转到结果页 |
| WebSocket 不同步 | 网络问题 | F5 刷新页面重连 |
| 账单未生成 | Kafka 消费延迟 | 手动触发 billing 事件 |

### 演示环境检查清单

- [ ] 所有 Docker 服务状态为 healthy
- [ ] 测试账号密码正确
- [ ] 浏览器已允许麦克风权限
- [ ] 已预生成候选人向量数据
- [ ] 已准备好转场话术（如跳过等待时间）
- [ ] 辅助人员已就位监控后台日志
